# Microsoft Fabric Toolbox

A collection of practical Microsoft Fabric demos, notebooks, API examples, and tools.

This repository contains things I've built while working with Microsoft Fabric that may also be useful to others. Some are reusable tools, while others are small examples created to demonstrate or explore specific Fabric functionality.

## What's included

Content may include:

* Utility notebooks for working with Fabric APIs
* REST API examples
* Fabric administration and automation examples
* Data engineering demos
* Identity and access control examples
* Troubleshooting and testing utilities
* Small proof-of-concept implementations

Each example has its own documentation explaining what it does, how to use it, and any prerequisites.

## Examples

### Pipeline metadata utility

Notebook examples for working with Fabric Data Pipeline metadata through the Fabric REST API, including scenarios such as updating pipeline metadata and testing how changes affect item ownership and modification information.

*More examples will be added over time.*

## Using the examples

Most examples are intended to be copied, modified, and used as starting points rather than treated as production-ready solutions.

Check the documentation included with each example for:

* Required permissions
* Authentication requirements
* Configuration values
* Known limitations

Microsoft Fabric evolves quickly, so APIs and behavior demonstrated here may change over time.
